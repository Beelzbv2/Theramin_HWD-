# Theramin_HWD-
Proyecto 2 de HWD creando un theramin con Arduino UNO
Trabajo realizado en C con la ayuda de Gemini para el codigo
ensamblado hecho por mi en tinkercad

Este proyecto se basa en la creacion de un instrumento con Hardware de arduino UNO
se puede dividir en distintos componentes:
Los pines controlando el pitch del theramin

El zumbador para reproducir o no(notone) algun sonido

El sensor para controlar el tono 

La breadboard con el Arduino para correr todo el programa
